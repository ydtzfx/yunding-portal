# v1.1.1 — Contract Aligned

Release date: 2026-09-20

This patch release aligns the frontend rendering model with the research publishing backend and makes that alignment enforceable in CI.

## Contract alignment

- one shared published-research service derived from Astro Content Collection types;
- research detail, cards, index, category, archive, author and related surfaces consume the same contract;
- static `/research/catalog.json` uses the same projection and powers client-side discovery;
- release manifest schema v2 captures the public research projection plus draft IDs;
- CI reconciles manifest, catalog and generated HTML before Pages deployment.

## Semantic correction

The first published report no longer carries a synthetic `updated` date equal to its original publication date.

An Updated label, Open Graph `article:modified_time` and JSON-LD `dateModified` are emitted only when a substantive backend update is explicitly recorded.

## Deployment gate

```text
content integrity
→ Astro build
→ static QA
→ release audit manifest
→ frontend/backend contract check
→ Pages artifact
```

This release does not add a database, API server or authentication layer. The portal remains a static, Git-based research publishing system.
