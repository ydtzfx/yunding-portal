# v1.1.0 — Operational Complete

Release date: 2026-09-20

This release closes the remaining frontend consistency and backend governance/reliability gaps after the v1.0.0 Institutional Grade baseline.

## Backend completion guarantees

- research report numbers are unique;
- author and related-research references must resolve;
- local attachments must exist;
- update dates cannot precede publication dates;
- report-number year must match publication year;
- published source URLs cannot be duplicated or placeholders;
- published reports require risk disclosure;
- inline source references cannot exceed the structured source list;
- every listed source in a published report must be cited inline;
- every verified build emits a release audit manifest with SHA-256 production-file hashes.

## Operations

- weekly published-source health monitoring;
- production uptime monitoring every six hours;
- weekly Git/content recovery snapshots with checksums;
- documented restore procedure and off-platform disaster-recovery boundary.

## Validated rehearsal

- content integrity: passed;
- 12 published source URLs checked: 11 healthy, 1 HTTP 405 classified as protected;
- production root/research/report/robots/sitemap: HTTP 200 + content markers passed;
- recovery bundle: checksum validation and `git bundle verify` passed.

## Architecture boundary

The portal remains intentionally database-free and authentication-free because it does not contain accounts, customer PII, payments, transactions, portfolio data or client-specific recommendations. Adding any of those capabilities requires a new backend threat-model, privacy and compliance review.
