# v1.0.0 — Institutional Grade Release

Release date: 2026-09-20

This release marks the first production baseline of the Yunding Investment Research Institute portal that is suitable for institutional research publishing.

## Release guarantees

- production build, security audit, and static QA are required before deployment;
- research publication is draft-gated and evidence-backed;
- institutional claims are evidence-gated;
- research pages carry structured identity, sources, risk disclosure, and Article SEO;
- legal/privacy/disclosure pages reflect the current static implementation and avoid unverified regulatory claims;
- production internal links, canonical URLs, sitemap, robots, 404 and report metadata are automatically checked.

## Verified release baseline

- Astro 7.3.3
- Node.js 22 CI/runtime target
- npm audit: 0 vulnerabilities at the final security-baseline verification
- production static QA: Green
- GitHub Pages: Green
- first published report: YD-MACRO-2026-001

## Scope boundary

This release is an institutional-grade **research publishing portal baseline**. It is not a claim that the organization has any particular legal entity, licence, regulatory registration, AUM, client base, track record, or named staff credentials beyond evidence explicitly reviewed and published on the site.
