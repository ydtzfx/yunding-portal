# v1.1.3 — Confidence Gated

Release date: 2026-09-21

This patch makes a 95/100 internal publication-confidence threshold enforceable across corporate identity, structured data, CI and production artifacts.

## Policy

- score >= 95: factual claim may be asserted;
- score < 95: claim must be qualified or withheld;
- scores are operational evidence ratings, not statistical probabilities.

## Refactoring triggered by the audit

- “Official Contact” → “Public Contact”
- “办公地址” → “联系地址”
- “正式邮箱” → “联系邮箱”
- ICP number → visibly qualified as enterprise-supplied and subject to MIIT live query
- legal entity / USCC / registered address / regulatory status → withheld
- ydtzfx.com → not used as canonical or Organization URL because ownership/control is not verified

A live GitHub-runner check on 2026-09-21 failed DNS resolution for `ydtzfx.com`, so its brand-association confidence was downgraded rather than promoted.

## Structured identity

Organization JSON-LD is now emitted site-wide using only allowed identity fields: brand name, brand translation, description, current production portal URL, contact address, telephone and email.

Article publisher metadata references that same Organization entity.

## Deployment gate

```text
content integrity
→ build
→ static QA
→ 95% confidence gate
→ release manifest
→ frontend/backend contract check
→ Pages artifact
```
