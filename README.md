# 芸鼎投资研究院企业门户网站

芸鼎投资研究院（Yunding Investment Research Institute）官方门户网站源码。

## 技术栈
- 纯静态 HTML + Tailwind CSS (CDN)
- 无需构建工具，可直接部署

## 页面结构
- `index.html` 首页
- `about.html` 关于我们
- `research.html` 研究观点
- `team.html` 团队介绍
- `contact.html` 联系我们
- `style.css` 全局样式

## 本地预览
直接用浏览器打开 `index.html` 即可预览。

## 部署到 GitHub Pages
1. 打开仓库 Settings → Pages
2. Source 选择 `main` 分支，目录选择 `/ (root)`
3. 保存后几分钟内即可通过 `https://ydtzfx.github.io/yunding-portal/` 访问
